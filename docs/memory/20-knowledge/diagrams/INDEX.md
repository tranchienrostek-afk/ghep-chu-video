# Diagram Index

Inventory important diagrams, including Excalidraw files, generated graphs, architecture maps, and workflow visualizations.

For each important diagram record:

- path/name;
- what it represents;
- related module/flow/roadmap;
- last known good commit/tag;
- whether it is protected by a checkpoint.

Do not assume a diagram is obsolete merely because the current UI no longer shows it. Check Git history first.
