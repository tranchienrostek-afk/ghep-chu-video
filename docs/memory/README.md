# Project Memory

This directory is the durable, navigable memory of the project.

Start at [`00-control/MAP.md`](00-control/MAP.md). Current working truth lives in `10-current/`. Stable knowledge lives in `20-knowledge/`. Durable decisions live in `30-decisions/`. Historical evolution and protected states live in `40-evolution/`.

The memory tree is not a diary. Keep current files compact; move detail into linked leaves with provenance.
